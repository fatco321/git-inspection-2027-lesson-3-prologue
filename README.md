# Пролог третьего урока

Отдельный клиентский проект на Vite, TypeScript и Babylon.js для пролога урока «Как работать с приложением „Мобильный инспектор“».

Первый вариант пролога: комната подготовки и мастерская, появление героев, диалог, переход Андрея в видеосвязь, получение приглашения и завершение перед чтением урока. Переключение реплик кнопкой «Далее».

Модели и портреты перенесены из предыдущих частей курса; сведения о лицензиях моделей сохранены рядом с файлами. Окружение и планшет созданы из геометрии Babylon.js.

## Запуск

```bash
npm install
npm run dev
```

Локальный адрес: http://127.0.0.1:5177/git-inspection-2027-lesson-3-prologue/

Проверка сборки: `npm run build`. Путь `base` в Vite уже подготовлен для будущей публикации на GitHub Pages. Проект пока не опубликован.

Локальный крупный план хвата: `?previewTablet`, обратный ракурс — `?previewTablet&view=3.3`. Параметры работают только в Vite dev и не отмечают пролог пройденным. Поза кистей рассчитывается относительно планшета, пальцы согнуты для бокового хвата. Мастерская включает видимый проход в складскую зону.

Проверка подъёма планшета по кадрам: `?previewTablet&previewPickup=0.65` (наклон), `previewPickup=1.3` (подъём), `previewPickup=2.1` (хват). Наклон распределён по Abdomen/Torso/Chest: Body не вращать для наклона, поскольку стопы этого рига находятся в отдельной ветке Root.

Осмотр окружения без персонажей: `?previewRoom`; крупные планы — `roomFocus=table` или `roomFocus=storage`, ракурс — `view=0.4`. Эти параметры доступны только в dev.
